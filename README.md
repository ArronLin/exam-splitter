# 试卷合订本拆分器

把“多套混排、双栏/三栏”的扫描试卷 PDF 合订本，自动拆成每套单栏的独立 PDF。

## 功能特性

- 一次选择多份 PDF 并行处理（默认并发 3，硬上限 4）
- 自动识别 1-up / 2-up / 3-up 版式，按实测栏线切分，避免把两栏内容挤成一页
- 分栏 OCR 识别学校名/届次，自动检测每套试卷的起止页并命名输出
- 输出 200 DPI 单栏 PDF（JPEG 压缩，体积小、肉眼无损）
- 服务端原生文件夹选择，显示完整路径，处理完成后自动保存
- 结果页可直接打开查看 / 下载 / 一键打开输出目录
- 版式校正面板：发现横版未拆分的页面时，可视化修改版式并增量重拆，无需手写 JSON
- 每份 PDF 可单独设置“跳过前导页数”（默认 2，用于跳过封面/目录）

## 目录结构

```
exam-splitter/
├── app.py                 # 独立本地 Web 应用（FastAPI 后端 + 内嵌前端）
├── scripts/               # 拆分流水线（run_pipeline.py + 四个 stage）
├── sample/                # 验证用样例合订本 PDF
├── runs/                  # 运行中间产物（自动创建，不入库）
├── requirements.txt
└── README.md
```

## 环境要求

- Python 3.14（或兼容 3.10+ 的版本，需支持 `sys.stdout.reconfigure`）
- 依赖：`pip install -r requirements.txt`
- Tesseract OCR（需 `chi_sim` 与 `eng` 语言包），默认从 `TESSERACT_EXE`、PATH 或
  `C:\Program Files\Tesseract-OCR\tesseract.exe` 查找

## 运行

```bash
python app.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:<port>`（默认从 8000 起找空闲端口）。

## 使用说明

1. 上传或拖拽合订本 PDF（可多选），每份可单独设置“跳过前导页数”；
2. 点“Browse”选择输出文件夹（也可直接输入完整路径）；
3. 点“开始处理”，等待完成（进度条实时显示阶段）；
4. 结果页每套试卷可“打开查看”“下载”，或“打开输出目录”；
5. 若某套试卷里仍有整张横版页，在“版式校正”面板把对应页码改成实际版式，
   点“应用校正并重新拆分”即可（只重 OCR 改动页，约 1 分钟内完成）。

## 拆分流水线

`scripts/run_pipeline.py` 依次执行四个阶段：

1. **Stage 1 版式识别**：按横向条带投票探测栏间空白，输出每页布局与实测栏线；
2. **Stage 2 分栏 OCR**：每栏独立高分 OCR + 整页顶部兜底，输出 `strips.json`；
3. **Stage 3 试卷检测**：根据学校名/届次/满分时间等特征划分试卷边界，输出 `exam_sets.json`；
4. **Stage 4 拆分导出**：按栏线把每套试卷切分为单栏 PDF，并生成 `_manifest.json` 清单。

也可单独调用流水线：

```bash
python scripts/run_pipeline.py \
  --pdf "合订本.pdf" \
  --out "输出目录" \
  --skip 2
```

## 样例

`sample/样例合订本.pdf` 是一份 9 页的真实样例，包含一页会被版式误判的页面，
可用于体验“版式校正”功能：上传后约 1 分钟完成，校正面板会列出该页，
改成双栏后重新拆分即可修复。
